# PageNest 1.18 阅读索引进度提示验证

## 优化内容

- 首次建立全书索引时，阅读页顶部显示轻量进度提示，不使用弹窗，也不阻断正文、翻页、进度调整或听书操作。
- 原生书籍解析阶段显示不确定进度；得到章节总数后切换为“已完成章节/总章节”的准确进度。
- 阅读工具栏显示时，索引提示自动下移，避免与书名、章节名和返回按钮重叠。
- 索引完成后提示自动消失；失败时显示简短说明，并在 4 秒后自动消失。
- 切换书籍或退出阅读页会取消旧索引并清理旧提示，避免跨书残留。
