# PageNest 1.13 阅读器稳定性验证记录

## 问题来源

2026-08-26 在目标小米 HyperOS 3 / Android 16 手机上测试 1.12 时，录屏和截图记录了以下问题：

- 阅读进度控制、语音控制和底部工具栏相互遮挡。
- 拖动进度条及切换阅读主题时应用退出并重新启动。
- 书架刷新提示中英文重叠。
- Azure 在线朗读失败回退时提示遮挡阅读控制。

附件只作为本地诊断证据，未提交包含用户通知或书籍内容的原始截图、录屏。

## 1.13 修复范围

- 进度拖动只在松手时跳转，跳转失败恢复到阅读器实际进度。
- 进度跳转先校验再修改章节/页码，避免失败后留下不一致状态。
- 进度面板打开期间禁止四秒自动隐藏，支持慢速拖动。
- 阅读控制、进度面板和语音面板采用单列堆叠并互斥展开。
- 纯颜色、背景图和文字颜色变化只刷新外观，不重新分页。
- 章节信息计算状态使用 `finally` 复位，避免异常后永久卡住。
- 书架提示改为有界、可关闭的纵向布局，并补齐全部语言资源。
- 在线转离线成功时使用播放器状态显示，不再弹出覆盖阅读器的提示；离线最终失败直接显示在迷你播放器中。

## 真机回归（发布后由目标设备执行）

当前电脑没有连接目标手机，因此以下项目不能由桌面测试替代：

1. 安装 1.13 APK，确认可覆盖升级且书架数据保留。
2. 打开 EPUB，拖动进度超过 5 秒再松手，确认只跳转一次且不退出。
3. 连续切换纯色、文字颜色和背景图，确认不退出且阅读位置不改变。
4. 同时操作进度、语音和显示面板，确认最多展开一个面板且控件不重叠。
5. 使用无效 Azure Key 测试自动回退：离线成功不弹遮挡提示；离线也失败时迷你播放器显示明确错误。
6. 返回书架刷新，确认提示不再中英文重叠。
