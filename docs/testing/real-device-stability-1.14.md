# PageNest 1.14 真机问题修复与系统复盘

## 问题来源

2026-08-26 在目标小米 HyperOS 3 / Android 16 手机上回归 1.12 和 1.13，发现阅读器崩溃、听书无响应、导入后书籍不自动显示、在线目录为空以及翻页不连贯等问题。原始截图、录屏和手机日志仅用于本地诊断，没有提交用户书籍内容或手机个人数据。

## 根因与修复

- EPUB 原生解析：修复 UTF-8 计数器在容器删除元素后继续引用已释放内存的问题；该问题同时导致打开书籍、调整字体和连续翻页崩溃。
- 后台听书：语音服务创建后立即发布前台通知，满足 Android 12+ / HyperOS 的前台服务时限。
- 在线发现：真实验证 Project Gutenberg 可用；将来源超时从 8 秒调整为 20 秒，适应手机 VPN、代理和移动网络链路。
- 本地导入：只要本次确实新增书籍，自动切到“全部书籍”并清除旧书架筛选。
- 翻页手势：按整段净位移判断完成或取消，避免松手前轻微回弹导致页面跳回；上下和左右翻页共用同一规则。
- 书架监听：配置变化使用最新任务替换旧任务，删除导入和筛选后的重复长期监听，避免排序、筛选更新失效。
- 工程兼容：将日志/换肤基础模块的 API 下限与其实际 API 使用对齐，恢复全工程 Lint 门禁。

## 系统性排查结论

- 原生容器检查未发现第二处“引用元素后删除容器元素”的同类业务代码。
- 前台服务入口只有语音播放一处，现已在服务创建阶段立即进入前台。
- 常规设置页没有横向分页或滑动切页代码；手机边缘左右滑触发的是 HyperOS 系统返回手势，不屏蔽系统返回能力。
- 导入结果提示已是有界、可关闭摘要，不再为每本书追加一行形成全屏遮挡。
- 启动时不会自动重复扫描已保存目录；扫描只在用户明确触发后执行。

## 真机回归清单

电脑当前未连接手机，以下项目需要安装 1.14 后在目标手机执行：

1. 覆盖安装并确认原书架数据保留。
2. 导入包含多本书的目录，完成后应自动显示“全部书籍”。
3. 打开《程序员的思维修炼》，连续上下翻页、修改字体和显示设置，确认不退出且翻页连贯。
4. 点击“听书”，确认出现后台播放通知；锁屏或切到后台后继续播放。
5. 在线发现等待最多 20 秒，验证推荐、热门、最新和书名搜索。
6. 在“系统配置 → 运行日志”确认没有新的 FATAL，告警不刷屏且日志大小受限。
