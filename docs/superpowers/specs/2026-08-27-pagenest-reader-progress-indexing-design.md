# PageNest 阅读进度与索引性能设计

## 背景与根因

当前首次打开书籍会在固定等待 1.5 秒后遍历全书统计字数。统计过程中，进度拖动直接返回失败且不保存用户目标；偏好变化和重复加载还可能重新启动整书工作，造成“无反应”、解析慢及频繁重排。

## 设计

- 每本书只允许一个字数索引任务运行，切换书籍时取消旧任务。
- 移除固定 1.5 秒等待，页面可用后立即在后台开始索引。
- 优先复用数据库已有总字数；只有缺失时才计算并持久化。
- 索引期间的进度拖动记录最后一个目标值，索引完成后自动执行一次；新的拖动覆盖旧目标。
- 切换书籍、加载失败或视图模型销毁时清除待处理目标，禁止目标串书。
- 字体/显示偏好只重排当前阅读上下文，不重启全书字数索引。

## 验收标准

1. 索引期间拖动进度不会丢失，完成后自动跳到最后选择的位置。
2. 同一本书重复触发加载不会并行或串行重复计算全书字数。
3. 已有总字数的书籍不启动全书索引。
4. 切换书籍不会应用上一书籍的待处理进度。
5. 上下翻页、字体调整、目录和听书的相关回归测试通过。
