# PageNest 运行与错误日志中心设计

日期：2026-08-26  
状态：已按用户的“自动选择推荐方案”授权通过  
目标分支：`master`

## 1. 目标

在 PageNest 的“我的”页面的系统配置区增加“运行与错误日志”入口，使用者能在不连接电脑的情况下查看最近运行事件、警告和错误。日志必须可控、不刷屏、不无限增长，且不泄露 API Key、授权头、URL 查询参数或本机绝对路径。

## 2. 方案选择

采用“应用私有滚动文件 + Timber 分级入口 + Compose 日志页”。不依赖 Logcat 读取权限，不引入云端日志 SDK，不上传任何日志。

## 3. 日志分级与写入规则

- `RUNNING`：只由新的显式运行事件 API 写入，用于应用启动、图书导入阶段、在线下载阶段、阅读器路由和语音会话生命周期。
- `WARNING`：持久化 `Logger.w(...)` 与显式告警。
- `ERROR`：持久化 `Logger.e(...)`、`Logger.wtf(...)` 与未捕获异常。
- 既有 `Logger.d/v/i(...)` 不写入文件，避免阅读排版、手势和 Compose 重组产生高频日志。
- 日志写入在单线程后台队列完成，不在主线程执行常规文件 I/O。
- 相同“级别 + 分类 + 脱敏后消息”在 10 秒窗口内只写一次；窗口后如有抑制，下一条附带“已抑制 N 条重复日志”。
- 每条日志的消息最长 2,000 字符，异常堆栈最多 20 行；换行在存储格式中转义，保持每条一行。

## 4. 存储上限与生命周期

- 目录：应用私有 `filesDir/diagnostics/`，无需存储权限，卸载应用时随应用数据删除。
- 文件：`pagenest-0.log` 为当前文件，轮转后依次为 `pagenest-1.log` 至 `pagenest-3.log`。
- 单文件硬上限 512 KiB，最多 4 个文件，总上限约 2 MiB。每次追加前预判写入后大小，超限先轮转。
- 启动时清理非法命名、超出保留个数或不可读的日志文件，但不扫描该私有目录之外的路径。
- 日志页默认只读最近 500 条，新日志在前；读取和清理均在后台执行。

## 5. 脱敏与隐私边界

在入队前对消息和堆栈做统一脱敏：

- `Authorization` / `Bearer` / `Api-Key` / `api_key` / `apikey` / `token` / `secret` 后的值替换为 `[REDACTED]`。
- HTTPS URL 的查询与 fragment 整体替换为 `?[REDACTED]`，保留协议、主机和路径以便定位来源。
- Windows、Unix 和 Android 应用数据绝对路径只保留文件名或 `[PRIVATE_PATH]`。
- 不记录图书正文、语音合成文本、完整 API 响应、完整阅读进度快照或用户选择的图片字节。
- 日志页首版不提供上传功能，不将日志复制到公共存储。

## 6. 崩溃与错误边界

- `BookApplication` 初始化文件日志后安装一层未捕获异常处理器。
- 处理器以同步、有界方式记录最后一条 `ERROR` 后，必须调用原处理器；日志失败不得阻断 Android 原有崩溃流程。
- 常规警告和错误不自动弹 Toast，不用日志页替代用户可操作的错误提示。

## 7. 界面与导航

- 在“我的”页的系统配置区，位于“通用”和“主题”附近，增加“运行与错误日志”条目。
- 日志页顶部提供返回、刷新和清空；清空必须二次确认。
- 筛选为“全部 / 运行 / 警告 / 错误”，同时显示当前文件总大小和上限说明。
- 单条显示本地时间、级别、分类和脱敏消息；空状态、读取失败和清理失败使用本地化文案。
- 页面支持大字体和纵向滚动，不使用固定高度的密集表格。

## 8. 首版必要埋点

- 应用进程：启动、版本号、上次未捕获异常。
- 私有图书导入：开始、格式、成功/重复、安全失败类别；不记录 URI 或绝对路径。
- 在线获取：开始、下载/验证/导入阶段、取消、失败枚举；不记录完整 URL。
- 阅读器：格式路由成功与找不到本地图书的告警；不记录图书正文。
- 语音：会话启动/停止、在线→离线回退、焦点/服务错误；不记录合成文本、API Key 或音频字节。

## 9. 测试与验收

- JVM 单元测试覆盖编码/解码、按时间倒序、轮转、总容量、并发、节流摘要、脱敏、堆栈截断、清理和损坏行容错。
- 未捕获异常处理器测试证明“先记录，后委派”且记录失败不吞掉原崩溃。
- ViewModel 测试覆盖加载、筛选、刷新、清理和错误状态。
- Compose 测试覆盖导航入口、分级筛选、空状态、清理确认与大字体可滚动结构。
- 发布门禁继续执行全部 JVM 测试、主 APK、Android-test APK 和 Lint，Lint 错误必须为 0。

## 10. 非目标

- 首版不接入 Sentry、Firebase Crashlytics 或任何云端日志服务。
- 不提供日志上传、远程查询、全文搜索、自定义容量或手动编辑日志。
- 不将 Logcat 整体复制到应用私有日志，不穷举替换所有现有 `android.util.Log` 调用。
