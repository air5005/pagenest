# PageNest 第 3 阶段：沉浸式阅读器设计

日期：2026-08-25  
状态：已确认（用户授权自动确认后续阶段）

## 1. 目标

在不重写现有 EPUB、TXT、FB2 等流式阅读内核的前提下，把主阅读界面升级为接近微信读书的清爽沉浸体验：默认只显示正文，中央轻触后出现必要控制，短暂无操作后自动收起；语音播放时保留轻量、可随时操作的迷你控制条。

本阶段不改动书籍解析、分页算法、阅读位置存储和语音后台服务协议。可提取文字 PDF 继续使用现有 PDF 阅读链路，统一 PDF 外观与交互留在后续独立阶段，避免把两套渲染器改造耦合在一起。

## 2. 已评估方案

### 方案 A：在现有阅读内核外增加沉浸式控制层（采用）

- 保留 `PageView`、`PageViewController` 和现有 ViewModel。
- 新增纯 Kotlin 的阅读器界面状态与状态转换策略。
- 重组 Compose 顶栏、底部操作区和语音迷你控制条。
- 优点：兼容风险低，状态逻辑可做 JVM 单元测试，能复用已有目录、进度、设置和语音能力。

### 方案 B：直接在现有工具栏中做样式修改

- 改动量较小，但自动隐藏、弹层互斥、语音常驻等状态仍散落在 Compose 和 ViewModel 中。
- 后续扩展困难，也较难稳定测试，不采用。

### 方案 C：为所有格式重写统一阅读页面

- 最终一致性最好，但会同时触碰流式文本和 PDF 渲染，回归面过大。
- 不符合当前阶段的小步发布原则，不采用。

## 3. 用户体验

### 3.1 默认阅读状态

- 打开章节后默认隐藏应用工具栏和系统栏，只显示正文与阅读引擎自身的页码提示。
- 保持用户当前字体、排版、背景、翻页方式和换肤设置。
- 点击屏幕中央切换控制层显示状态；翻页手势仍由现有阅读引擎处理。

### 3.2 顶部信息栏

- 左侧为返回按钮。
- 中间显示书名和当前章节，过长时省略。
- 右侧保留书签入口，并提供更多入口访问笔记、高亮、书籍信息等原有能力。
- 使用半透明圆角表面，颜色跟随当前主题和阅读背景，减少对正文的遮挡。

### 3.3 底部快捷控制

控制层显示时，底部提供四个主要入口：

1. 目录：打开现有章节抽屉。
2. 进度：显示当前进度及滑块，并可前后翻页。
3. 听书：首次点击准备并启动语音；正在播放时打开完整语音面板。
4. 显示：打开现有显示设置，字体、页面和阅读设置继续从这里访问。

原有笔记、高亮、书签列表和书籍详情不删除，通过顶部更多入口承载。

### 3.4 自动隐藏规则

- 控制层显示且没有弹层时，4 秒无操作后自动隐藏。
- 用户操作进度条、打开设置、目录、笔记、高亮、书签、文字选择菜单或语音完整面板时不自动隐藏。
- 关闭最后一个弹层后重新开始计时。
- 再次中央轻触可立即隐藏控制层。
- Android 系统栏与控制层同步显示和隐藏。

### 3.5 语音迷你控制条

- 语音会话处于播放、暂停或准备状态时，底部显示迷你控制条，不依赖主控制层是否可见。
- 展示章节/引擎简要状态、上一段、播放/暂停、下一段和关闭。
- 点击文字区域或扩展入口打开已有完整语音控制面板，用于语速、音调、声音和定时设置。
- 熄屏或切到后台后仍由现有前台 `MediaSession` 服务继续播放。

## 4. 状态模型

新增纯 Kotlin 状态模型，至少表达：

- 主控制层是否显示；
- 当前是否存在阻止自动隐藏的弹层；
- 语音会话是否需要显示迷你条；
- 完整语音面板是否展开；
- 自动隐藏计时代次，用于丢弃过期计时事件。

状态转换由明确事件驱动：中央点击、用户交互、打开/关闭弹层、语音状态变化、自动隐藏超时。Compose 仅负责渲染和转发事件，避免把互斥规则散落在多个 `remember` 中。

## 5. 数据与兼容性

- 继续使用 `MainReadViewModel.showMenu` 作为控制层对外状态，逐步由新策略统一更新。
- 阅读进度仍来自 `readProgression`，跳转仍调用 `changePageByProgress`。
- 目录、注释、笔记、书签和各项显示设置继续调用现有 ViewModel 方法。
- 语音继续使用 `SpeechSettingsViewModel`、`ReaderSpeechManager` 和后台播放服务。
- 不修改数据库结构，不需要迁移。

## 6. 异常与边界

- 书籍尚未加载时不显示可操作控制层。
- 当前页无可朗读文字时，不创建空语音会话，沿用现有提示/空操作保护。
- 打开外部链接确认框、笔记对话框或文字选择工具栏时，主控制层不抢占点击。
- 旋转、进后台或 Compose 重组后，不重复启动语音；阅读会话释放规则保持不变。
- 返回键优先关闭当前弹层；没有弹层时返回书架。

## 7. 测试与验收

### JVM 单元测试

- 默认沉浸状态。
- 中央点击显示/隐藏。
- 超时只隐藏当前代次的控制层，过期计时无效。
- 弹层打开时阻止自动隐藏，关闭后恢复计时。
- 语音状态决定迷你条可见性，停止后隐藏。
- 完整语音面板和主快捷控制的互斥关系。

### Compose 测试

- 隐藏状态不显示顶部和底部操作。
- 显示状态包含目录、进度、听书和显示四个入口。
- 语音活跃时显示迷你控制，并可触发播放/暂停与展开操作。
- 浅色、深色主题内容可读，主要按钮具有可访问名称。

### 模拟器验收

- API 36 模拟器导入测试书并打开。
- 中央轻触、自动隐藏、目录、进度、显示设置和返回路径可用。
- 在线/离线语音入口、迷你控制和后台播放不回归。
- 全量 JVM 测试、Android 测试、构建和 Lint 通过后发布 APK。
