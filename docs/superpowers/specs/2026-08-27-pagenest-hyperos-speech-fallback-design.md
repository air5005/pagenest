# PageNest HyperOS 系统语音兼容设计

## 背景与根因

真机日志显示 HyperOS 已成功绑定并初始化 `com.xiaomi.mibrain.speech`。现有实现仍要求语音服务枚举出语言完全匹配、且明确标记为无需网络的音色；小米默认音色未满足该枚举条件，导致应用在调用 `speak` 前错误返回“系统语音引擎不可用”。

## 设计

- 保留系统语言能力检查：缺语言数据和不支持语言仍返回明确错误。
- 请求指定音色时，仅在该音色存在且可选择时选择它。
- 未指定音色，或系统没有公开可用的离线音色时，使用已经初始化成功的系统默认音色继续朗读。
- 真正的启动返回错误、播放回调错误或初始化失败，才报告系统语音失败。
- 音色列表仍只展示明确可离线使用的音色，不把未知能力的默认音色伪装成离线音色。
- AUTO 模式没有可用 Azure 配置时直接选择系统语音，避免无意义的联网尝试和误导性 Azure 错误。

## 验收标准

1. HyperOS TTS 已初始化、支持 `zh-CN`、但音色列表为空时仍能调用系统 `speak`。
2. 指定不存在的音色时回退系统默认音色，不阻断朗读。
3. 不支持语言、缺语言包、系统启动和播放失败仍返回原有精确错误。
4. 离线、在线、自动路由及关闭/并发测试全部通过。
5. 生成可安装 APK；真机断开时明确标记 HyperOS 回归待验证。
