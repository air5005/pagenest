# PageNest 一键图片换肤设计

## 目标

用户从首页右上角菜单选择一张相册图片或已有书籍封面后，一次操作同时更新首页与可重排阅读页背景，并在重启后保留。用户也可以一次恢复两处默认背景。

## 交互

- 首页菜单入口命名为“一键图片换肤”。
- 弹窗可选择已有书籍封面、从系统相册选择图片；已有皮肤时显示“恢复默认皮肤”。
- 成功、无效图片、图片过大、读取失败和设置保存失败均显示中文提示。
- 相册使用系统文件选择器，不额外申请存储权限。

## 数据与安全

- 支持 JPEG、PNG、WebP 和 GIF 文件头，输入上限 25 MB，源图片最大边长 32768 像素。
- 导入时复制到应用私有 `files/skins`，将最长边压缩到不超过 2048 像素并转为 JPEG。
- 目标文件以压缩后内容的 SHA-256 命名，通过临时文件、落盘同步和原子移动发布，避免半写文件；相机照片的 EXIF 方向会在压缩前应用。
- 首页和阅读页设置按同一事务式流程写入，最后以单个原子文件作为提交点；任一写入失败时提交点保持旧值并尝试恢复两处旧值，重启后会按提交点自动修复中断写入。
- 服务为应用级单例，避免多窗口或多个页面实例并发导入时交叉写入。
- 只保留当前提交的私有皮肤，失败导入、旧皮肤和遗留临时文件会被清理。
- 阅读页在后台线程解码并缓存位图；发现文件缺失、损坏、内存不足或解码失败时回退到背景色，不影响打开书籍。

## 测试策略

- 服务测试覆盖双端应用、写入顺序、失败回滚、重置和协程取消。
- Android 导入测试覆盖有效图片、降采样、私有存储、无效图片和超限图片。
- 阅读页测试覆盖自定义图片解码以及缺失、损坏文件回退。
- 完成前执行完整单元测试、Debug APK、测试 APK 和 Lint 门禁。
