# 羿巢阅读（YiNest）

> 一款面向 Android 与小米 HyperOS 3 的现代阅读应用。
>
> A modern reading app for Android and Xiaomi HyperOS 3.

## 项目简介

羿巢阅读希望为用户提供安静、简洁、专注的数字阅读体验。名字中的“羿”来自两个孩子共同的名字，“巢”代表一家人共同建立的家。项目将围绕本地阅读与个人阅读管理逐步建设，界面与交互会针对 Android 及小米 HyperOS 3 进行适配。

## 计划功能

- 个人书架与书籍管理
- 本地书籍导入
- 沉浸式阅读器
- 阅读进度记录
- 划线、笔记与书签
- 字体、字号、行距和阅读主题设置
- 深色模式与 HyperOS 3 体验适配

## 技术方向

- Kotlin
- Jetpack Compose
- Material 3
- Android Jetpack

具体架构与依赖会在首个可运行版本设计完成后确定。

## 开发方式

项目采用测试驱动开发（TDD），遵循以下循环：

1. **RED**：先编写失败的测试。
2. **GREEN**：编写最小实现，让测试通过。
3. **REFACTOR**：在测试保护下重构代码。

## 当前状态

项目处于初始化阶段。下一步将创建 Android 工程骨架，并确定首个可交付版本的功能范围。
